# 5. 器と提出

対応: `read.frame.shell`

---

## 5.1 器

### `index.html`

| 要素 | 内容 |
| --- | --- |
| `<canvas id="c">` | `width=640` `height=360`。`aria-label="Random Duel Rainbow game"` |
| `<p id="k">` | **操作説明の置き場所。**中身は実行時に `CONTROLS` から生成する |
| `<meta viewport>` | `width=device-width,initial-scale=1` |

**HTML は操作の文言を持たない。**二重管理にしない。

### CSS

| 規則 | 値 |
| --- | --- |
| 中央寄せ | `display:grid` ＋ `place-items:center` |
| 幅 | `min(100vw, 1120px, 177vh − 84px)` |
| 縦横比 | `aspect-ratio: 16/9` ＋ `width: 100%` |
| 拡大 | `image-rendering: pixelated` |
| スクロール | `overflow: hidden` |
| 背景 | `#070812`、キャンバスは `#090a16` |
| 700px 未満 | `main` の余白を 0、操作行を 10px / 行送り 1.4 へ |

**幅と高さの両方で詰める。**`177vh` は `100vh × 16/9`、`84px` は上下の余白と操作行ぶん。

| 窓 | キャンバス |
| --- | --- |
| 320 × 568 | 320 × 180 |
| 800 × 300 | 423 × 238 |
| 900 × 450 | 689 × 387 |
| 1280 × 600 | 954 × 537 |
| 1280 × 720 以上・幅1120以上 | 1096 × 617（上限） |

**どの窓でも操作行は消えない。**幅が足りなければ2行へ折り返す。

## 5.2 ビルド

```
node prismatic-duel/build.mjs
```

| 段 | 処理 |
| --- | --- |
| 1 | JS を圧縮（複数回畳み込み・トップレベル名短縮・コメント除去） |
| 2 | CSS の空白とコメントを除去 |
| 3 | `index.html` の外部参照をインライン文字列へ置換 |
| 4 | **`index.html` 1枚だけ**を含む最小 ZIP を組み立てる |
| 5 | **inlined と ZIP の両方を表示し、13,312 超で終了コード1** |

**ZIP ライブラリを依存に足さない。**ローカルヘッダー・中央ディレクトリ・
終端レコードを直接書く（ファイル名固定・単一ファイル）。

**ビルドは道具であって提出物ではない。容量に含めない。**
開発専用の検査関数（`validateBoss`）は未使用として圧縮時に消える。

### 容量の3つの段

| 段 | 意味 | 扱い |
| --- | --- | --- |
| ソース | 人が書くコード | **予算の単位にしない** |
| inlined | 1枚へ畳んだバイト数 | 配分の単位 |
| **ZIP** | 提出物 | **全体で1つのゲート。合否を決めるのはこれ** |

現在: inlined 22,900 / **ZIP 9,876 bytes（74.2% / 13,312・余裕 3,436）**。

## 5.3 提出

```
node prismatic-duel/submit.mjs
```

`dist/` は `.gitignore` されている。**提出物はリポジトリに残らない。**
残るのはソースだけで、**ZIP はコミットから再生成する。**

| 出すもの | 実体 |
| --- | --- |
| **遊べる ZIP** | `prismatic-duel/dist/prismatic-duel.zip` |
| **読めるソース** | リポジトリを、提出したコミットで指す |

### 検査（すべて合否に含む）

| 段 | 検査 |
| --- | --- |
| 1 | **2回ビルドして ZIP の SHA-256 が一致する** |
| 2 | ZIP の中身が **`index.html` 1件だけ**で、ディレクトリを挟まない |
| 3 | 展開した中身がビルド出力と**1バイトも違わない** |
| 4 | HTML に**外部参照が0件** |
| 5 | **13,312 bytes 以下** |

### 印（合否に含まない）

作業ツリーが clean か、HEAD が `origin` にあるか。**提出の直前に揃っていることを見る。**

### 提出票

検査を通ると `dist/SUBMISSION.txt` を書き出す。

```
提出 ZIP     prismatic-duel/dist/prismatic-duel.zip
             9876 bytes / 13312 (74.2%)
             sha256 ...
読めるソース <リポジトリ>/tree/<コミット>
             コミット <40桁>
             作業ツリー clean / 送信済み
```

## 5.4 受け入れ条件

| 条件 | 判定 |
| --- | --- |
| **提出可能** | ZIP が 13,312 bytes 以下で、展開して `index.html` を開くだけで**ネット接続なしに遊べる** |
| **外部リソース非依存** | 成果物が `index.html` 1枚だけで、`http` で始まる参照が0件 |
| **最上位に `index.html`** | ZIP の中身が `index.html` 1件だけ |
| **16:9 の維持** | 320px 〜 2560px で縦横比が崩れず、スクロールバーが出ない |
| **操作の提示** | どの窓でも操作行が消えない |
| **読めるソース** | リポジトリのソースがコメント付きで、ビルドが通る |
| **ビルドが上限を守らせる** | 意図的に肥大させたコードで**終了コードが1になる** |

### 大会の制約

| | |
| --- | --- |
| 上限 | ZIP 13,312 bytes |
| 締切 | 2026-09-13 20:00 JST |
| テーマ | Unicorns and Rainbows |
| 提出物 | 遊べる ZIP と、ビルド可能な読めるソースの**両方** |

## 5.5 開発用の道具

**すべて提出物に入らない。**

| ファイル | 内容 |
| --- | --- |
| `build.mjs` | 提出ビルド（5.2） |
| `submit.mjs` | 提出検証（5.3） |
| `test.mjs` | 30,000体の生成検査 |
| `steal.test.mjs` | 奪取の回帰テスト |
| `sim.mjs` | ヘッドレス戦闘シミュレータ |
| `moves.mjs` | 技構成のダンプと分布統計 |

`game.js` の先頭は関数へ依存しない生成器なので、
`test.mjs` はブラウザを起動せず `generateBoss()` / `validateBoss()` を直接呼ぶ。
