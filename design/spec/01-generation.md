# 1. 生成

対応: `duel.gen`（`move` / `roster` / `audit`）

シードとtierから、**ボス1体の不変な設計データ**を返す。
現在HP・座標・行動タイマーは含まない。

---

## 1.1 技の語彙（`move`）

技は**9要素の配列**。

```
m = [S, D, R, W, A, C, T, N, F]
```

| 添字 | 名 | 範囲 | 意味 |
| --- | --- | --- | --- |
| `S` | shape | 0〜5 | 形状 |
| `D` | damage | 1〜4 | プレイヤーHPから直接引く量 |
| `R` | range | 1〜4 | 射程の段。`REACH` で実ピクセルへ |
| `W` | windup | 1〜4 | 予備動作の段。`WIND` で実フレームへ |
| `A` | active | 1〜3 | 判定持続の段。`ACTIVE` で実フレームへ |
| `C` | recovery | 1〜4 | 攻撃後硬直の段。`REC` で実フレームへ |
| `T` | tracking | 0〜2 | 予備動作中の追尾と弾の曲がり |
| `N` | repeat | 1〜3 | 段数 |
| `F` | flags | ビット和 | 有効な回答の宣言 |

### 変換表

| 段 | 1 | 2 | 3 | 4 |
| --- | ---: | ---: | ---: | ---: |
| `WIND`（予備動作F） | 24 | 36 | 54 | 80 |
| `ACTIVE`（持続F） | 5 | 8 | 12 | — |
| `REC`（硬直F） | 18 | 32 | 50 | 76 |
| `REACH`（射程px） | 48 | 82 | 136 | 250 |

**フレーム数を直接抽選しない。**段だけを抽選し、表を通す。

### 形状

| `S` | 名 | 展開 |
| --- | --- | --- |
| 0 | `SWEEP` | 床上24pxの横長矩形 |
| 1 | `THRUST` | 四足の胴体の高さへ向ける高さ18pxの矩形 |
| 2 | `SLAM` | 自分を中心とする地上の広い矩形 |
| 3 | `CHARGE` | 移動中の本体矩形 |
| 4 | `SHOT` | 弾を生成する（矩形を持たない） |
| 5 | `RAIN` | 確定した落下Xの縦矩形 |

### 宣言フラグ

| 値 | 名 | 意味 |
| --- | --- | --- |
| 1 | `PARRY` | パリィが有効 |
| 2 | `JUMPABLE` | ジャンプで抜けられる |
| 4 | `MOVEABLE` | 移動で避けられる |

形状から機械的に決まる。

| `S` | `MOVEABLE` | `PARRY` | `JUMPABLE` |
| --- | :---: | :---: | :---: |
| 0 `SWEEP` | ✅ | ✅ | ✅ |
| 1 `THRUST` | ✅ | ✅ | |
| 2 `SLAM` | ✅ | ✅ | |
| 3 `CHARGE` | ✅ | ✅ | ✅ |
| 4 `SHOT` | ✅ | ✅ | |
| 5 `RAIN` | ✅ | | |

## 1.2 危険度（`threat`）

```
threat(m) = DMG_COST[D] + RANGE_COST[R] + WIND_COST[W] + REC_COST[C]
          + T×2 + (N−1)×2 + (A===3 ? 2 : 0)
```

| 段 | 1 | 2 | 3 | 4 |
| --- | ---: | ---: | ---: | ---: |
| `DMG_COST`（威力） | +1 | +3 | +6 | +9 |
| `RANGE_COST`（射程） | 0 | +1 | +3 | +5 |
| `WIND_COST`（予備動作） | **+4** | +2 | 0 | **−2** |
| `REC_COST`（硬直） | 0 | −1 | −3 | −5 |

加点: 威力・射程・短い予備動作・追尾・多段・長い持続
減点: 長い予備動作・長い硬直

### 帯域（`limits`）

```
limits(tier, signature) = signature ? [6+tier, 8+tier×2] : [3+tier, 6+tier]
```

| tier | 通常技 | 固有技 |
| --- | --- | --- |
| 0 | 3〜6 | 6〜8 |
| 1 | 4〜7 | 7〜10 |
| 2 | 5〜8 | 8〜12 |

### 合計上限（`budgetCap`）

```
budgetCap(tier) = 24 + tier×6
```

| tier | 0 | 1 | 2 |
| --- | ---: | ---: | ---: |
| 合計上限 | 24 | 30 | 36 |

**2層構造。**帯域は技1つを抑え、合計上限はセット全体を抑える。

---

## 1.3 禁止構成（`harden`）

危険度の合計に関わらず、次の組み合わせを崩す。**`balance` の反復中も毎回通す。**

| 条件 | 強制する値 |
| --- | --- |
| `W===1`（24F） | `D≤2`、`T≤1`、`N=1` |
| `D===4` かつ `R===4` | `W≥3`、`C≥3` |
| `R===4` かつ `T===2` | `D≤2`、`W≥2` |
| `N===3` | `D=1` |
| `A===3` かつ `T===2` | `T=1` |

---

## 1.4 帯域への収束（`balance`）

最大 **24回**の単調補正。毎回 `harden` を通す。

| 状態 | 補正の順 |
| --- | --- |
| **危険度 > 上限** | 硬直+1 → 予備動作+1 → 追尾−1 → 段数−1 → 威力−1 → 射程−1 |
| **危険度 < 下限** | 硬直−1 → 予備動作−1 → 威力+1 → 射程+1 |
| 帯域内 | 打ち切る |

各段は上限（`C`,`W`,`R`,`D` は4、`N` は3、`A` は3、`T` は2）で止まる。

## 1.5 技1つの生成（`makeMove`）

```
makeMove(r, shape, tier, signature) -> Move
```

| 順 | 決めるもの | 規則 |
| --- | --- | --- |
| 1 | 射程 `R` | 形状ごとの許可域から抽選 |
| 2 | 威力 `D` | `1 + rand(min(4, 2+tier+(signature?1:0)))` |
| 3 | 予備動作 `W` | `1 + rand(4)` |
| 4 | 持続 `A` | `1 + rand(2)` |
| 5 | 硬直 `C` | `1 + rand(4)` |
| 6 | 追尾 `T` | 形状が `SHOT`/`RAIN` のときだけ `rand(min(3, tier+2))`、他は 0 |
| 7 | 段数 `N` | 固有技のみ。`r>.55` で 2、tier2 かつ `r>.82` で 3 |
| 8 | 持続 `A` | 固有技のみ。`r>.7` で 3 |
| 9 | 宣言 `F` | 形状から機械的に（1.1 の表） |
| 10 | — | `balance(m, tier, signature)` |

### 形状ごとの許可射程

| `S` | 0 `SWEEP` | 1 `THRUST` | 2 `SLAM` | 3 `CHARGE` | 4 `SHOT` | 5 `RAIN` |
| --- | --- | --- | --- | --- | --- | --- |
| `R` の範囲 | 2〜3 | 1〜3 | 1〜2 | 3〜4 | 3〜4 | 3〜4 |

### 抽選域の tier 依存

| | tier 0 通常 | tier 0 固有 | tier 1 通常 | tier 1 固有 | tier 2 通常 | tier 2 固有 |
| --- | --- | --- | --- | --- | --- | --- |
| 威力 `D` | 1〜2 | 1〜3 | 1〜3 | 1〜4 | 1〜4 | 1〜4 |
| 追尾 `T` | 0〜1 | 0〜1 | 0〜2 | 0〜2 | 0〜2 | 0〜2 |
| 段数 `N` | 1 | 1〜2 | 1 | 1〜2 | 1 | 1〜3 |

## 1.6 ボス1体の生成（`roster`）

```
generateBoss(seed, tier) -> ボスの不変データ
```

### 技の役割枠

| tier | 枠 | 技数 |
| --- | --- | ---: |
| 0 | `THRUST` / `SWEEP` / `CHARGE`か`SHOT` / `SLAM`か`RAIN` | 4 |
| 1・2 | `THRUST` / `SWEEP` / `CHARGE`か`SHOT` / `SHOT`か`RAIN` / `SLAM`か`CHARGE`か`RAIN` | 5 |

**最後の枠が固有技**（`signature`）。

### 生成の手順

| 段 | 処理 |
| --- | --- |
| 1 | シードと tier から専用乱数列を作る |
| 2 | 役割枠を決める |
| 3 | 各枠を `makeMove()` で数値化する |
| 4 | **3番目の枠が `CHARGE` でなければ `R=4` にする。**超過分は硬直→予備動作→威力の順に返す（最大8回） |
| 5 | **固有技に `C≥3` を強制する。** |
| 6 | **`C≥3` の技が2つ未満なら、`C<3` の通常技のうち最も危険度が高いものにも `C≥3` を強制する** |
| 7 | **`W===1`（24F）の技を1つ以下にする。**2つ目以降は `W=2` へ落とし、下限を割ったぶんを威力→射程→硬直で返す |
| 8 | **合計が `budgetCap(tier)` 以下になるまで削る**（最大60回） |
| 9 | 防御を決める |
| 10 | 主色と異名を決める |

### 段5・6 の下限固定（`open`）

硬直を `C≥3` に固定したまま、危険度が `帯域の下限−2` を下回っていれば
次の順で最大8回押し上げる。**`harden` が値を戻したら打ち切る。**

```
N===3 かつ D===1 → N=2 → W===1 かつ D===2 → W=2 → D+1 → R+1 → W−1
```

### 段8 の削り

合計が上限を超えている間、**帯域の下限を上回っている技のうち最も危険度が高いもの**を
次の順で1段だけ削る。**すべての技が下限に張り付いていたら打ち切る。**

```
C+1 → W+1 → T−1 → N−1 → D−1 → R−1
```

`harden` が値を押し戻したら打ち切る。

### 防御

```
defense = tier ? 1 + rand(3) : 0
```

| 値 | 名 | 効果 |
| --- | --- | --- |
| 0 | 無し | tier 0 は必ずこれ |
| 1 | `ARMOR` | 通常時の体勢ダメージ **×0.5** |
| 2 | `BARRIER` | バリア有効中、弾のHPダメージ **×0.3**。近接命中で **180F** 破壊 |
| 3 | `SHIELD` | 山札一巡ごとに **60F** 構える。構え中はHP **×0.3**・体勢 **×0.35** |

### 主色と異名

生成された特徴から候補を作り、そこから1つ選ぶ。

| 候補 | 条件 |
| --- | --- |
| 0 赤 `CRIMSON` | `D≥3` の技がある |
| 1 橙 `AMBER` | `A===3` の技がある |
| 2 黄 `GOLDEN` | `W≤2` の技がある |
| 3 緑 `VERDANT` | 防御を持つ |
| 4 青 `AZURE` | `R===4` の技がある |
| 5 藍 `INDIGO` | `T≥1` の技がある |
| 6 紫 `VIOLET` | `N>1` の技がある |

候補が空なら 0。**異名 = 色の名 ＋ 固有技の形状に対応する武器名。**

| `S` | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| 武器名 | `BLADE` | `LANCE` | `HAMMER` | `HORN` | `ORBIT` | `CROWN` |

### 体力

| tier | 0 | 1 | 2 |
| --- | ---: | ---: | ---: |
| `maxHp` | 120 | 160 | 210 |
| `maxPosture` | 24 | 32 | 42 |

## 1.7 検査（`audit`）

```
validateBoss(b) -> エラー名の配列
```

**開発専用。**未使用関数として提出版の圧縮時に消える。

### セット単位

| 検査 | 条件 |
| --- | --- |
| `move count` | 技数が tier 0 で4、tier 1・2 で5 |
| `no jump answer` | `JUMPABLE` を持つ技が1つ以上 |
| `too few parries` | `PARRY` を持つ技が2つ以上 |
| `no gap pressure` | `R===4` または `CHARGE` の技が1つ以上 |
| `too few openings` | `C≥3`（50F以上）の技が2つ以上 |
| `too many fast moves` | `W===1`（24F）の技が1つ以下 |
| `budget cap` | 危険度の合計が `budgetCap(tier)` 以下 |

### 技単位

| 検査 | 条件 |
| --- | --- |
| `budget` | 危険度が帯域内。**`C≥3` の技は下限を2まで下回ってよい** |
| `fast lethal range` | `D===4` かつ `R===4` なら `W≥3` かつ `C≥3` |
| `fast overload` | `W===1` なら `D≤2` かつ `T≤1` かつ `N===1` |
| `tracking overload` | `R===4` かつ `T===2` なら `D≤2` かつ `W≥2` |
| `invalid number` | 全要素が有限数 |

### 回帰テスト

| ファイル | 内容 |
| --- | --- |
| `test.mjs` | **10,000シード × 3 tier = 30,000体。**エラー配列が空であること、および同一シードのバイト一致 |
| `steal.test.mjs` | **28,000技の変換規則**、全6形状の連続3回使用、多段の落下位置確定 |
