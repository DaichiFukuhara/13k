ここで記載した仕様は実装済み。人による初見評価は未実施で、[音の検証記録](../PLAYTEST_2026-09-12.md)と[戦闘の記録](../PLAYTEST_2026-09-10.md)に範囲を残す。

- 主人公は一本角を持つ四足のユニコーン。角で攻撃・パリィを行い、倒した敵の技の型を1つだけ角へ写す。
- 技は横薙ぎ＝押し戻し、突き＝短い隙、叩きつけ＝体勢崩し、突進＝接近、射撃＝足を止めた遠隔、落下＝位置を読んだ置き技として使い分ける。
- 角の型の交換は戦い方の交換であり、HP威力や所持枠の成長ではない。解放した光は3撃破で背景の虹を復元する。
- 基礎HP威力の正規化を維持し、形状別の発生・硬直・ST・移動・体勢効果と四足の被弾範囲を調整対象にする。

## 1. ゲームの形

**シードから技構成だけを生成した未知の敵を、観察して崩す1画面固定の2Dボスアクション。**

- 1ランは**ボス3体**。順に tier 0 / 1 / 2
- 操作キャラは**1人**。残機・控え・交代は無い
- ボスを倒すたびに、**その相手の技を1つ選んで自分の攻撃と置き換える**
- 確定前にJ/Zで選んだ技を安全な標的へ試せる。Rで選び直し、Enterで確定する。試用は任意で戦績には含めない
- 3体倒すと Result。死ぬと同じ敵からやり直す

## 3. 乱数

| 列 | シード | 使い道 |
| --- | --- | --- |
| ボス生成 | `runSeed(i) = (seed ^ imul(i+1, 0x85ebca6b)) >>> 0` → さらに `seed ^ imul(tier+1, 0x9e3779b9)` | 技構成・防御・主色 |
| 山札 | `boss.seed + 周回数 × 97` | 技の出る順 |
| 背景の星 | 固定 `71` | 星の座標 |
| 火花・画面揺れ | `Math.random()` | 見た目のみ |

生成器は Mulberry32 系（`seeded()`）。**同じシードは同じ敵を返す。**
見た目の乱数は生成の乱数列を消費しない。

シードの表示は32bit整数の**36進数・大文字・6桁ゼロ詰め**。
URL の `?seed=` を36進数として読む。

## 4. 不変条件

1. 提出 ZIP は 13,312 bytes 以下。最上位に `index.html` を置く
2. 外部リソースに依存しない（CDN・外部画像・外部フォント・外部API を使わない）
3. 画像ファイル・音声ファイル・外部ライブラリを持たない。描画と音は実行時に生成する
4. **生成するのは敵の技構成であって、戦闘中の当たり判定ではない。**
   攻撃開始後に発生時刻・範囲・形・標的位置を乱数で変えない
5. **予告した危険範囲と実際の当たり判定は、同一の定義から作る**（`moveRect()`）
6. **同じシードは同じ敵を再現する。**負けた直後に別の敵へ変わらない
7. **色だけに依存させない。**範囲・時間・動きでも同じ情報を示す
8. **奪った技はプレイヤーを強くしない。**所持は常に1つ、攻撃力は正規化する。
   技の数・攻撃力・耐久のどれもランの進行で上がらない
9. 難易度が上がる経路は**敵側の危険度予算だけ**
10. 音は情報の主経路にしない。**切っても読める**

## 5. 用語

| 語 | 意味 |
| --- | --- |
| **技（Move）** | 9要素の配列 `[S,D,R,W,A,C,T,N,F]`。[1. 生成](01-generation.md) |
| **危険度（threat）** | 技1つの強さを表す整数。加点と減点の和 |
| **帯域（limits）** | tier と枠ごとに決まる危険度の下限・上限 |
| **合計上限（budgetCap）** | ボス1体が持てる危険度の合計 |
| **固有技（signature）** | 技配列の最後の1つ。帯域が通常技より上 |
| **段（pulse）** | 多段攻撃の1回ぶん |
| **体勢（posture）** | ボスの第2ゲージ。0で 110F の大きな隙 |
| **所持技（hold）** | プレイヤーの攻撃。常に1つ |

## 6. この版に無いもの

**次の版へ送ったもの。仕様として存在しない。**

- 技1つ単位の公平性検査（安全席の検査・回答2つの検査）
- 予備動作が短い技の選択時条件
- ラン全体（3体ぶん）の一括生成。**現在は1体ずつ生成する**
- 主色を「最も危険度へ寄与した特性」から決めること。**現在は候補集合からランダム**
- SHOT の宣言フラグに `PARRY` を立てること。**現在は弾側が `parry` を持つ**
