# 2. 戦闘

対応: `duel.fight`（`avatar` / `foe` / `arena`）

## 次期仕様：6形状の役割と角の行動（未実装）

正本は[根の次期設計](../tree/index.md) `decision-14` の1・4・5。
基礎HP威力は全段合計で正規化し、押し戻し/体勢/移動/照準で役割を変える。
形状別の発生・硬直・STと被弾範囲の数値表はduelで詳細化する。以下の旧数値を次期の確定値とは扱わない。

| 形状 | 固有効果 | 代償 |
| --- | --- | --- |
| SWEEP | 低い弧と押し戻し | 突きより遅く、命中後に距離が開く |
| THRUST | 初期の角突き。短い隙へ差し込む | 細く、大きな接近・押し戻し・体勢の特典なし |
| SLAM | 長い構えから体勢を大きく削る | 空振りと短い隙に弱い |
| CHARGE | 角を向けて自分が接近する | 敵の近くに残る。追尾/無敵なし |
| SHOT | 角から遠隔の直進弾 | 構えから発生終了まで足が止まり、着弾に時間がかかる |
| RAIN | 自分の位置/向き/射程で狙った場所へ遅れて落とす | 開始時に全段の照準固定。敵に自動吸着しない |

押し戻しと体勢効果は一攻撃あたりに上限を設け、多段数倍の特典と無限拘束を防ぐ。
角パリィ・回避は既存の成功条件を継承する。四足の胴体に合う被弾範囲は攻撃原点と一緒に定義して検査する。
生成器・敵の9要素・危険度予算は初期実装で維持し、特定技の所持が必須になる敵を作らない。

## 2026-09-08 更新: 判定のフィードバックと試用

この節は以下の基準仕様へ追加する現行差分。生成器・HP14・攻撃の威力/ST式・3連戦は同じ。

- `lesson(m)` は形状と対処フラグから短い対処例を返す。安全な回答の保証ではない。
- `feedback={text,kind,ttl}` は実際の命中/反撃/パリィ/被弾/ST不足から発生する。
  counterは命中前の敵がrecover/staggerである場合だけ。空振りを成功と表示しない。
- `lastLesson` は実被弾の技名と対処。敵弾は発射時の原因を保持し、現在の敵の技で推測しない。
- 撃破候補 `take` は `list/i/held/foe{name,hue}` を公開する。試用しただけでは元の所持技を確定しない。
- 選択画面でJ/Zを押すと `trial`。本戦と同じ移動・攻撃・弾・ST処理で、攻撃しない標的に技を試す。
- trialのRはカーソルを保って候補へ戻る。Enterは選んだ技を確定し次戦、最終撃破ならResultへ。
- 試用はrunの時間・被弾・パリィ・撃破ログ・敵生成を変えない。標的HPが尽きても撃破や第2形態へ移らない。
- 試用退出時に弾・効果・一時入力を破棄。Escape/blurはfight/trialを覚えてpauseし、同じ状態へ復帰する。
- 画面揺れの減衰は更新側に置く。描画関数は状態を更新しない。

## 2.2 奪取（`arena`）

**ボスを倒すと、その相手の全技＋現在の所持技から1つ選ぶ。所持は常に1つ。**

### 変換規則

```
steal(m) -> プレイヤー版の技
```

| 扱い | 要素 |
| --- | --- |
| **引き継ぐ** | 形状 `S` / 射程 `R` / 予備動作の段 `W` / 持続 `A` / 硬直 `C` / 段数 `N` |
| **正規化する** | 威力 `D` を **3 に固定** |
| **捨てる** | 追尾 `T` → 0、宣言 `F` → 0 |

### 変換後に付く値

| 値 | 式 | 結果 |
| --- | --- | --- |
| `cost` | `clamp(10 + threat(t)×2, 12, 40)` | スタミナ消費 |
| `wind` | `WIND[W−1] >> 1` | **実フレームは半減**（12 / 18 / 27 / 40F） |
| `seg` | 合計 **7** を段数で割り、余りを前の段から配る | `[7]` / `[4,3]` / `[3,2,2]` |

**総HPダメージは段数によらず 7。**多段の利点は体勢削りだけ（1段につき体勢 1）。

### 素手

奪取の出発点。ランの開始時と、新しいランを始めたときの所持技。

```
steal([1,3,1,3,1,2,0,1,0]) のあと cost=14, wind=9 を固定
```

| 値 | |
| --- | --- |
| 形状 | `THRUST` |
| 射程 | 48px |
| 予備動作 | **9F**（変換表の外の固定値） |
| 硬直 | 32F |
| 消費 | **14**（固定値） |
| 色 | 無色 |

### 選択

| | |
| --- | --- |
| 候補 | 倒したボスの全技を `steal()` したもの **＋ 現在の所持技** |
| 操作 | ←/→ で選択、Enter で確定 |
| 持ち越し | **死亡してやり直しても所持技は保たれる。**新しいランで素手へ戻る |

確定すると `[異名, 主色, 選んだ技]` がランの記録へ積まれる。

## 2.3 プレイヤーの攻撃

**ボスと同じ時間割・同じ展開器で動く。**

```
全長 = wind + (ACTIVE[A−1] + 10) × N + REC[C−1]
1段の長さ span = ACTIVE[A−1] + 10
```

| 形状 | 動き |
| --- | --- |
| `SHOT` | 段が変わった最初のフレームに弾を1発生成。速度 `face × 5.4`、寿命 150F |
| `CHARGE` | 判定中、自分が `face × (3.2 + R×0.72)` px/F 前進 |
| その他 | `local < ACTIVE[A−1]` の間、`moveRect()` の矩形をボス本体と判定 |
| `RAIN` | **攻撃開始時に全段ぶんの落下Xを確定する** |

命中は「攻撃番号:段番号」ごとに**1回だけ。**

### 多段の展開位置

```
基準 = 自分のX + 向き × REACH[R−1]
i段目 = 基準 + (i===0 ? 0 : (i%2 ? +1 : −1) × (55 + 18×i))
```

30 〜 610 でクランプ。**ボスの多段も同じ式。**

| 距離 | 動き |
| --- | --- |

### 技の選択

| 段 | 処理 |
| --- | --- |
| 1 | **山札が空なら全技をシャッフルして補充する。**シードは `ボスseed + 周回数×97` |
| 2 | **先頭3枚を見る。**距離 < 150px、または `R≥3`、または `CHARGE` の最初の1枚を選ぶ |
| 3 | 該当が無ければ先頭を使う |

**一巡するまで同じ技は戻らない。**

### 弾（`SHOT`）

| 値 | 式 |
| --- | --- |
| 速度 | `3.1 + (5 − W) × 0.45` |

## 2.5 攻撃範囲（`moveRect`）

**予告表示と当たり判定が共有する唯一の形状定義。**原点はボスにもプレイヤーにも差し替わる。

```
moveRect(m, pulse, src) -> {x, y, w, h}
reach = REACH[R−1]、dir = src.face
```

| `S` | 矩形 |
| --- | --- |
| 0 `SWEEP` | `x = dir<0 ? ox−reach : ox+前面幅`、`y = 283`、`w = reach`、`h = 24` |
| 1 `THRUST` | `x` は同上、`y = oy + (プレイヤー 4 / ボス 26)`、`w = reach`、`h = 18` |
| 2 `SLAM` | `x = ox − reach×0.55`、`y = 250`、`w = reach + 44`、`h = 57` |
| 3 `CHARGE` | 本体の当たり判定そのもの |
| 4 `SHOT` | 空の矩形（弾が担当） |
| 5 `RAIN` | `w = 28 + R×9`、`x = targets[pulse] − w/2`、`y = 18`、`h = 289` |

前面幅: プレイヤー 12 / ボス 40（`SWEEP`）・38（`THRUST`）。

## 2.6 ダメージ

### ボスが受ける

**唯一の入口。**種別は `melee` と `shot` の2つ。

| 順 | 条件 | 効果 |
| --- | --- | --- |
| 1 | `shift` 中 | **無効** |
| 2 | `guard` 中 | HP ×0.3、体勢 ×0.35 |
| 3 | `BARRIER` かつ `shot` かつバリア健在 | HP ×0.3 |
| 4 | `ARMOR` かつ `recover`/`stagger` 以外 | 体勢 ×0.5 |
| 5 | `melee` かつ `BARRIER` | **バリアを 180F 破壊する** |
| 6 | `recover` / `stagger` 中 | **HP ×1.25** |

適用後、HP0 なら撃破。次に最終形態への移行、最後に体勢0の判定。

### プレイヤーが受ける

| 順 | 判定 |
| --- | --- |
| 1 | 無敵中・ローリング無敵中・同一IDからの再ヒットなら**無効** |
| 2 | HP を `m[D]` 引く。無敵 42F、被弾硬直 12F |
| 3 | HP0 で敗北 |

### パリィ

| 対象 | 効果 |
| --- | --- |
| 近接（`PARRY` を持つ技） | **体勢 −8。**パリィ硬直を解除。体勢0なら `stagger`、残っていれば `recover` 42F |
| 弾（`parry` を持つ弾） | **反射。**所有者が反転し、速度 `vx × −1.35` / `vy × −1`、威力 3、体勢 7 |

### 体勢

0 になると `stagger` 110F。終了時に全回復。
