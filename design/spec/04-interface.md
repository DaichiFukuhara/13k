# 4. 画面

対応: `read.frame`（`hud` / `screens` / `sound`）

## 次期仕様：角に宿す型と虹の復元（未実装）

正本は[根の次期設計](../tree/index.md) `decision-14` の1・4・5。

- タイトルで「ユニコーンの角に敵の技を1つ写し、3体の守護者から虹を取り戻す」という目的を短く伝える。
- 技の候補には「得意な状況」「代償」を各1句で示す。例：突進は「距離を詰める／敵の近くに残る」。
- 確定時だけ敵の残光→角→所持技を示す。所持技を保つ場合は型を保ち、虹の復元は撃破数に従って進む。
- 試用は仮の型と分かる表示にし、Rで元に戻る。試用でも押し戻し・体勢・移動制限・照準を確認できる。
- 虹の復元は3撃破で完了する。試用・候補変更・リトライで二重加算せず、新ランで初期状態へ戻る。
- 現行キーと直接確定を維持する。物語や獲得演出のために追加の操作や強制待ちを要求しない。

## 2026-09-08 更新: 目的・理由・奪取を画面へ出す

この節の方針を優先する。以下の旧配置の細部は実装時のレイアウト調整を許す。

- タイトルに「敵を倒して技を1つ奪い、次の敵に使う」という目的を表示する。
- HUDにHP/ST/体勢の役割、現在の予告と対処例、反撃の隙、短い色凡例を示す。
- 実際に発生したfeedbackを表示し、counter/parryとhurt/tiredを区別する。
- 死亡画面にlastLessonを表示し、同じ敵へ再挑戦して試す対処を伝える。
- 技選択のカードは間合い・速さ・隙・段数・消費を短い言葉で説明する。
  元所持技の印は `take.held`、撃破した相手の表示は `take.foe` に従う。
- trialでは候補カードの代わりに、操作できる試し場と戻る/確定操作を表示する。
- 試用は任意。最後の撃破後も直接確定/試用/戻るを同じ操作で行える。

| 画面 | 追加・更新された操作 |
| --- | --- |
| bosswin | ←/→ またはA/Dで選択、J/Zで試用、Enterで確定 |
| trial | 通常の移動・ジャンプ・攻撃、Rで候補へ戻る、Enterで確定 |
| pause | Enter/Escapeで直前のfightまたはtrialへ戻る |

fightとtrialのフォーカス喪失は自動pause。文字が敵と予告や操作を隠さないよう配置する。
描画側は入力や状態を更新せず、表示専用である。

### 操作の提示

**操作の割当は1か所（`CONTROLS`）だけが持つ。**HTML は置き場所だけを用意する。

| 操作 | キー |

| `MOVE` | `A/D or arrows` |
| `JUMP` | `W/Up/Space` |
| `ATTACK` | `J/Z` |
| `PARRY` | `K/X` |
| `ROLL` | `L/C` |

**どの画面幅・画面高でも隠さない。**幅が足りなければ折り返す（[5. 器と提出](05-shell.md)）。

## 4.3 奪取の選択画面

**撃破画面が選択画面を兼ねる。**画面を増やさない。

| 要素 | |
| --- | --- |
| 背景 | (24, 60) から 592 × 240 の暗幕 |
| 見出し | `PRISM SHATTERED` (320, 96) 22px |
| 説明 | `TAKE ONE MOVE   ←/→ CHOOSE   ENTER CONFIRM` (320, 120) 10px |
| 札の幅 | `min(96, 560 / 候補数)` |
| 脚注 | 異名 ＋ `LAST PRISM` または `PRISM n/3 NEXT` (320, 285) |

### 1枚の札

| 行 | 内容 | y |
| --- | --- | ---: |
| 帯 | 技の色（4px） | 146 |
| 形状名 | `SWEEP` など | 168 |
| 射程 | `136px` | 186 |
| 予備動作 | `18F WIND` | 200 |
| 硬直 | `32F REC` | 212 |
| 段数 | `2 HITS`（`N>1` のときだけ） | 224 |
| 消費 | `28 ST`。**26超で赤、以下は黄** | 240 |
| 所持中 | `HELD`（緑） | 256 |

**威力は表示しない。**正規化されて全候補で同じ。
出るのは**間合い・速さ・代償**だけ。

選択中の札は不透明・白枠2px、それ以外は `α = 0.4`・枠1px。

## 4.5 音（`sound`）

**音声ファイルを持たない。**オシレータ1つ＋ゲイン1つで1音を作る。

### 1音の形

| 要素 | 規則 |
| --- | --- |
| 周波数 | 開始値から `max(40, f × 0.65)` まで指数で下降 |
| 音量 | 開始値から 0.0001 まで指数で下降 |
| 長さ | 呼び出しごとに指定 |

`AudioContext` は**最初のキー入力で作る。**停止中なら再開する。

### 技の音

**波形が形状、高さが速さ。**

```
moveTone(m, windF, pulse) = (300 − windF × 2.2) × 1.33^pulse
```

- **速い技ほど高い**
- **段が上がるごとに完全4度ぶん上がる**（多段はリズムになる）
- **ボス側は 0.6 倍**で鳴らす

| `S` | 0 `SWEEP` | 1 `THRUST` | 2 `SLAM` | 3 `CHARGE` | 4 `SHOT` | 5 `RAIN` |
| --- | --- | --- | --- | --- | --- | --- |
| 波形 | `square` | `square` | `triangle` | `triangle` | `sawtooth` | `triangle` |

| 契機 | 高さ | 波形 | 長さ / 音量 |
| --- | --- | --- | --- |
| プレイヤーの攻撃発生 | `moveTone(m, wind)` | 形状の波形 | .07 / .025 |
| プレイヤーの弾 | `moveTone(m, wind, 段)` | `sawtooth` | .06 / .022 |
| プレイヤーの多段命中 | `moveTone(m, wind, 段)` | 形状の波形 | .05 / .02 |
| ボスの予備動作開始 | `moveTone(m, WIND) × 0.6` | 形状の波形 | .09 / .03 |
| ボスの弾 | `moveTone(m, WIND, 段) × 0.6` | `sawtooth` | .08 / .028 |

**敵の技と自分の技が同じ規則で鳴る。**

### 状態の音

| 契機 | 高さ | 波形 | 長さ / 音量 |
| --- | ---: | --- | --- |
| ジャンプ | 170 | `sine` | .05 / .018 |
| ローリング | 110 | `sine` | .05 / .02 |
| パリィ開始 | 280 | `triangle` | .04 / .02 |
| パリィ成功 | 1100 | `square` | .10 / .055 |
| 弾の反射 | 960 | `square` | .08 / .05 |
| 体勢崩し | 880 | `square` | .18 / .05 |
| プレイヤー被弾 | 75 | `sawtooth` | .16 / .045 |
| ボス撃破 | 70 | `sawtooth` | .50 / .05 |
| 最終形態 | 65 | `sawtooth` | .35 / .04 |
| 技の確定 | 520 | `square` | .10 / .04 |
| 新シード | 300 | `square` | .05 / .035 |

**音は情報の主経路にしない。**予備動作は画面の予告が既に示しているので、
音を切っても同じ判断ができる。
