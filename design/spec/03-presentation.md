# 3. 提示

対応: `read.tell`（`actors` / `telegraph` / `palette`）

**画像ファイルを持たない。**すべて Canvas の図形で描く。

---

## 3.1 色（`palette`）

### 7色の語彙

| # | 色 | 名 | 意味 |
| ---: | --- | --- | --- |
| 0 | `#ed596f` | `CRIMSON` 赤 | 高威力 |
| 1 | `#ec9348` | `AMBER` 橙 | 長い持続 |
| 2 | `#ead85b` | `GOLDEN` 黄 | 速い予備動作 |
| 3 | `#5dcc8a` | `VERDANT` 緑 | 防御 |
| 4 | `#5ea8e8` | `AZURE` 青 | 長射程 |
| 5 | `#746ae6` | `INDIGO` 藍 | 追尾 |
| 6 | `#bd64e6` | `VIOLET` 紫 | 多段 |

### 攻撃の色（ボス側）

**優先順に最初に当たったもの。**該当が無ければボスの主色。

| 順 | 条件 | 色 |
| ---: | --- | --- |
| 1 | `D ≥ 4` | 赤 |
| 2 | `T ≥ 1` | 藍 |
| 3 | `W === 1` | 黄 |
| 4 | `R === 4` | 青 |
| 5 | `N > 1` | 紫 |
| — | 上記以外 | ボスの主色 |

### 所持技の色（プレイヤー側）

**変換後の実際の値で決め直す。**出るのは4色と無色だけ。

| 順 | 条件 | 色 |
| ---: | --- | --- |
| 1 | 素手 | `#c9c6d8` 無色 |
| 2 | `wind ≤ 18F` | 黄 |
| 3 | `R === 4` | 青 |
| 4 | `N > 1` | 紫 |
| 5 | `A === 3` | 橙 |
| — | 上記以外 | `#c9c6d8` 無色 |

**赤は出ない**（威力を正規化するため）。**藍も出ない**（追尾を捨てるため）。
**緑も出ない**（攻撃技ではないため）。

### 色に依存しない経路

**すべての情報は色以外にも出る。**

| 情報 | 色以外の経路 |
| --- | --- |
| 攻撃範囲 | 予告の矩形の形と大きさ |
| 速さ | 予告が濃くなる時間 |
| 段数 | 判定が出る回数 |
| 射程 | 武器の長さ（プレイヤー） |
| ゲージ | 位置と太さ（3.4） |

## 3.2 予告（`telegraph`）

**`wind` と `active` の間だけ描く。**矩形は `moveRect()` の戻り値をそのまま使う。

| 状態 | 描画 |
| --- | --- |
| `wind`（`SHOT` 以外） | 塗り `α = 0.08 + 経過率 × 0.2`、枠線 `α = 0.4` |
| `wind`（`SHOT`） | 本体から射程の先へ**射線**を引く。`α = 0.15 + 経過率 × 0.4` |
| `active`（`SHOT` 以外） | 現在段の矩形を `α = 0.45` で塗る |

経過率 = `1 − 残りタイマー / WIND[W−1]`。**予告は時間とともに濃くなる。**

## 3.3 キャラクター（`actors`）

### プレイヤー

棒人間。頭（半径5の円）＋胴＋脚2本＋腕2本＋武器1本。

| 状態 | 描画 |
| --- | --- |
| ローリング無敵中 | `α = 0.55` |
| ローリング中 | 全体が 8px 沈む |
| パリィ中 | 前方に半径12の弧。**受付中は不透明、それ以外は `α = 0.25`** |

### 攻撃モーション

**所持技の性格が姿に出る。**

| 局面 | 腕の振り `sw` |
| --- | --- |
| 予備動作中（`t < wind`） | `−t / wind`（引く） |
| 発生以降 | `min(1, (t − wind) / 6)`（振り抜く） |

| 値 | 式 |
| --- | --- |
| 武器の長さ | `14 + REACH[R−1] × 0.14 × (振り抜き中は sw、それ以外 0.3)` |
| 武器の色 | 所持技の色（3.1） |
| 武器の太さ | 振り抜き中 5、それ以外 4 |
| 向き | `face` で左右反転 |

### ボス

頭（半径8の円・線幅5）＋胴（28×42の矩形）＋脚2本＋武器1本。

| 要素 | 規則 |
| --- | --- |
| 輪郭の色 | 主色 |
| 武器の長さ | `28 + R × 8` |
| 武器の太さ | `SLAM` のとき 8、それ以外 4 |
| 胸の帯 | **7色を3×22の縦棒で並べ、主色だけ不透明**（他は `α = 0.25`） |
| `stagger` 中 | 全体を −0.2 rad 傾ける |
| `BARRIER` 健在 | 半径34の緑の円（`α = 0.45`） |
| `guard` 中 | 前面に 18×58 の緑の板 |

### 火花

当たり判定を持たない。

| 契機 | 数 | 色 |
| --- | ---: | --- |
| ボス被弾 | 7 | ボスの主色 |
| プレイヤー被弾 | 12 | プレイヤーの色 |
| パリィ成功 | 18 | 白 |
| 体勢崩し | 22 | 白 |

初速はランダム方向 0.5〜3.0、上向き −1 のバイアス。重力 +0.09 /F、寿命 16〜31F。

### 背景

| 層 | 内容 |
| --- | --- |
| 空 | `#090a19` → `#171226` の縦グラデーション |
| 星 | 70個。固定シード。`α = 0.25 + 大きさ × 0.2` |
| 柱 | 58px おきに 34×77 の矩形（`#1f1830`）。上端を `230 + (x % 3) × 8` で3段ずらす |
| 床 | y=307 から下（`#2b2038`）。上端に2pxの線（`#594569`） |

### 描画順

```
背景 → 予告 → 弾 → プレイヤー → ボス → 火花 → HUD → 画面別オーバーレイ
```

**描画は判定を一切変更しない。**
