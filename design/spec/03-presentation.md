# 3. 提示

対応: `read.tell`（`actors` / `telegraph` / `palette`）

**画像ファイルを持たない。**すべて Canvas の図形で描く。

## 現行仕様：四足のユニコーンと角の光（2026-09-09実装）

2026-09-10のdecision-15差分: バリア輪郭は通常時かつ未破壊のときだけ描く。`recover/stagger`中は消え、実際の射撃が通る窓と一致する。

正本は[根の次期設計](../tree/index.md) `decision-14` の1・4・5。
主人公は一本角、馬の頭胴、四肢、たてがみと尾で識別する。以下の人型・腕・手持ち武器の主人公表現を置き換えた。この節を優先する。

- 初期攻撃は角突き。横薙ぎは角の弧、叩きつけは前脚の踏み込みと角から地面への光、突進は角を向けた疾走。
- 射撃は角からの直進光、落下は角から上へ放ち地面へ落とす光。武器を持ち替えず6形状を再現する。
- パリィ成功で角に虹の閃光を出す。角を常に発光させて成功中と誤認させない。
- 見える胴体・被弾範囲・角と攻撃の原点をduelの共通状態から描く。一本角や尾の飾りを独自の判定にしない。
- RAINの入力前の狙いと入力後に固定した全段の印を区別する。危険予告と物語の虹を重ねて隠さない。
- 角の技色は正規化後の実性能に従う。背景の虹の復元は3撃破の進行を示し、技色の全色収集は要求しない。

## 2026-09-08 更新: 見切れる構えと攻撃予告

この節は以下の基準仕様の姿勢・予告を更新する。色の分類と当たり判定は変更しない。

- プレイヤーと敵は、構え・攻撃の発生・攻撃後硬直を身体/腕/武器の姿勢で区別する。
- 全6形状は共通の戦闘状態/経過Fから描く。武器の装飾で判定位置を変更しない。
- windの予告充填は実際の残りwind時間に従う。色だけで発生タイミングを示さない。
- 多段RAINは後段の落下位置も同じ `moveRect(m,pulse)` から予告する。
- CHARGEは進行方向を示す。独立した架空の攻撃矩形を描かない。
- trialの標的も同じ戦闘描画で確認できる。描画でHP/座標/timer/乱数列を変更しない。
- Canvas図形のみを使用し、外部画像やフォントを追加しない。

### 攻撃の色（ボス側）

**優先順に最初に当たったもの。**該当が無ければボスの主色。

| 順 | 条件 | 色 |
| ---: | --- | --- |
| 1 | `D ≥ 4` | 赤 |
| 2 | `T ≥ 1` | 藍 |
| 3 | `W === 1` | 黄 |
| 4 | `R === 4` | 青 |
| 5 | `N > 1` | 紫 |
| — | 上記以外 | ボスの主色 |

### 所持技の色（プレイヤー側）

**変換後の実際の値で決め直す。**出るのは4色と無色だけ。

| 順 | 条件 | 色 |
| ---: | --- | --- |
| 1 | 素手 | `#c9c6d8` 無色 |
| 2 | `wind ≤ 18F` | 黄 |
| 3 | `R === 4` | 青 |
| 4 | `N > 1` | 紫 |
| 5 | `A === 3` | 橙 |
| — | 上記以外 | `#c9c6d8` 無色 |

**赤は出ない**（威力を正規化するため）。**藍も出ない**（追尾を捨てるため）。
**緑も出ない**（攻撃技ではないため）。

### 色に依存しない経路

**すべての情報は色以外にも出る。**

| 情報 | 色以外の経路 |
| --- | --- |
| 攻撃範囲 | 予告の矩形の形と大きさ |
| 速さ | 予告が濃くなる時間 |
| 段数 | 判定が出る回数 |
| 射程 | 武器の長さ（プレイヤー） |
| ゲージ | 位置と太さ（3.4） |

## 3.2 予告（`telegraph`）

**`wind` と `active` の間だけ描く。**矩形は `moveRect()` の戻り値をそのまま使う。

| 状態 | 描画 |
| --- | --- |
| `wind`（`SHOT` 以外） | 塗り `α = 0.08 + 経過率 × 0.2`、枠線 `α = 0.4` |
| `wind`（`SHOT`） | 本体から射程の先へ**射線**を引く。`α = 0.15 + 経過率 × 0.4` |
| `active`（`SHOT` 以外） | 現在段の矩形を `α = 0.45` で塗る |

経過率 = `1 − 残りタイマー / WIND[W−1]`。**予告は時間とともに濃くなる。**

## 3.3 キャラクター（`actors`）

### プレイヤー

棒人間。頭（半径5の円）＋胴＋脚2本＋腕2本＋武器1本。

| 状態 | 描画 |
| --- | --- |
| ローリング無敵中 | `α = 0.55` |
| ローリング中 | 全体が 8px 沈む |
| パリィ中 | 前方に半径12の弧。**受付中は不透明、それ以外は `α = 0.25`** |

### 攻撃モーション

**所持技の性格が姿に出る。**

| 局面 | 腕の振り `sw` |
| --- | --- |
| 予備動作中（`t < wind`） | `−t / wind`（引く） |
| 発生以降 | `min(1, (t − wind) / 6)`（振り抜く） |

| 値 | 式 |
| --- | --- |
| 武器の長さ | `14 + REACH[R−1] × 0.14 × (振り抜き中は sw、それ以外 0.3)` |
| 武器の色 | 所持技の色（3.1） |
| 武器の太さ | 振り抜き中 5、それ以外 4 |
| 向き | `face` で左右反転 |

### ボス

頭（半径8の円・線幅5）＋胴（28×42の矩形）＋脚2本＋武器1本。

| 要素 | 規則 |
| --- | --- |
| 輪郭の色 | 主色 |
| 武器の長さ | `28 + R × 8` |
| 武器の太さ | `SLAM` のとき 8、それ以外 4 |
| 胸の帯 | **7色を3×22の縦棒で並べ、主色だけ不透明**（他は `α = 0.25`） |
| `stagger` 中 | 全体を −0.2 rad 傾ける |
| `BARRIER` 有効（未破壊かつ反撃窓の外） | 半径34の緑の円（`α = 0.45`） |
| `guard` 中 | 前面に 18×58 の緑の板 |
