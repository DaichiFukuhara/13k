## 1. これは何を決めるものか

**提出物の形と、それを作る道具。**

### 1.1 器（容量に含まれる 600 bytes）

| ファイル | 中身 |
| --- | --- |
| `index.html` | `<canvas>` 1枚 ＋ **操作説明を置く空の場所**（中身は `screens` が `s1.controls` から生成する。`frame` の親に残すもの6）＋ 読み込み |
| CSS | 画面中央寄せ・**16:9 の維持**・背景・ピクセル補間なし |

**CSS の要点**（実装から）:

- `place-items: center` で中央寄せ
- `aspect-ratio: 16/9` ＋ `width: 100%` で**どの窓でも 16:9 を保つ**
- `image-rendering: pixelated` で**内部解像度 640×360 を拡大しても滲ませない**
- `overflow: hidden` で**スクロールさせない**（根の 1.7）
- **操作の段落は、どの画面幅でも隠さない。**幅が足りなければ折り返して2行にする
- **幅だけでなく高さでも詰める。**`width: min(100vw, 1120px, 177vh - 84px)`

> 🔒 **凍結（`shell@2026-09-05-decision-3`）。**実装は 700px 未満で `<p>` を隠していたが、
> **審査員がノートPCの狭い窓で開くと操作が分からず、受け入れ条件「初見」が落ちる。**
> 隠さない。**文字列は `screens` が `s1.controls` から生成する**（`frame` の親に残すもの6）ので、
> `shell` は場所だけ用意する。

> 🔒 **凍結（`shell@2026-09-06-decision-4`）。高さでも詰める。**
> **横幅だけを見ていたので、低い窓で下端が切り落とされていた**（7-2 の実測）。
> `overflow: hidden` があるため、あふれた分はスクロールもされず**ただ消える。**
> 16:9 を保ったまま高さに合わせて縮める。`177vh` は `100vh × 16/9`、
> `84px` は上下の余白と操作行ぶんの引き当て。
> **上の凍結（隠さない）と同じものを守っている** — 幅で消さないと決めたものを、
> 高さで消させない。

### 1.4 読めるソースも提出する（根の 5-A-5）

**遊べる ZIP と、ビルド可能な読めるソースの両方を提出する。**

- ZIP に入るのは**圧縮済みの `index.html` 1枚**
- リポジトリには**コメント付きのソース**が残る
- **開発専用の検査関数は、圧縮時に未使用として落ちる**
  （実装の `validateBoss` がそうなっている）

#### 1.4.1 提出手順（`shell@2026-09-06-decision-4`。7-4 の解消）

**`dist/` は `.gitignore` されているので、提出物はリポジトリに残らない。**
残るのはソースだけで、**ZIP はコミットから再生成する。**
だから成立の条件は1つ — **同じコミットからは同じ ZIP が出ること。**

| 出すもの | 実体 |
| --- | --- |
| **遊べる ZIP** | `prismatic-duel/dist/prismatic-duel.zip`（提出の直前に生成する） |
| **読めるソース** | `origin` のリポジトリを、提出したコミットで指す |

**手順は `prismatic-duel/submit.mjs` 1本にまとめる**（道具なので容量に含めない）。

| 段 | 検査 | 根拠 |
| --- | --- | --- |
| 1 | **2回ビルドして ZIP の SHA-256 が一致する** | 再現性。これが無いと「ソースから作れる」が嘘になる |
| 2 | ZIP の中身が **`index.html` 1件だけ**で、ディレクトリを挟まない | 5-A-1 |
| 3 | 展開した中身が `dist/index.html` と**1バイトも違わない** | 「配ったもの」と「作ったもの」の一致 |
| 4 | HTML に**外部参照が1つも無い** | 5-A-2 |
| 5 | **13,312 bytes 以下** | 5-A-1 |

**git の状態（未コミット・未 push）は印として出すだけで、合否には含めない。**
作業中でも検査を回せるようにするため。**提出の直前に印が揃っていることを見る。**

検査を通ると `dist/SUBMISSION.txt` を書き出す。ZIP のバイト数と SHA-256、
提出したコミット、ソースの URL が1枚に載る。**提出後に「どれを出したか」を
言い当てられるのはこの1枚だけである**（`dist/` は git に残らないため）。

**実測（2026-09-06）**: 5項目とも OK。ZIP 9,876 bytes（74.2%・余裕 3,436）。
