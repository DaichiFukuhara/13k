## 1. これは何を決めるものか

**提出物の形と、それを作る道具。**

### 1.1 器（容量に含まれる 600 bytes）

| ファイル | 中身 |
| --- | --- |
| `index.html` | `<canvas>` 1枚 ＋ **操作説明を置く空の場所**（中身は `screens` が `s1.controls` から生成する。`frame` の親に残すもの6）＋ 読み込み |
| CSS | 画面中央寄せ・**16:9 の維持**・背景・ピクセル補間なし |

**CSS の要点**（実装から）:

- `place-items: center` で中央寄せ
- `aspect-ratio: 16/9` ＋ `width: 100%` で**どの窓でも 16:9 を保つ**
- `image-rendering: pixelated` で**内部解像度 640×360 を拡大しても滲ませない**
- `overflow: hidden` で**スクロールさせない**（根の 1.7）
- **操作の段落は、どの画面幅でも隠さない。**幅が足りなければ折り返して2行にする

> 🔒 **凍結（`shell@2026-09-05-decision-3`）。**実装は 700px 未満で `<p>` を隠していたが、
> **審査員がノートPCの狭い窓で開くと操作が分からず、受け入れ条件「初見」が落ちる。**
> 隠さない。**文字列は `screens` が `s1.controls` から生成する**（`frame` の親に残すもの6）ので、
> `shell` は場所だけ用意する。

### 1.2 ビルド（容量に含まれない道具）

**根の親に残すもの10 が仕様を固定している。**

| 段 | 処理 |
| --- | --- |
| 1 | JS を圧縮・変数名短縮・コメント除去（複数回畳み込み、トップレベル名も短縮） |
| 2 | CSS の空白とコメントを除去 |
| 3 | `index.html` の外部参照を**インライン文字列へ置換** |
| 4 | **`index.html` 1枚だけ**を含む最小 ZIP を組み立てる |
| 5 | **inlined と ZIP の両方を表示し、13,312 超で終了コード1** |

**ZIP ライブラリを依存に増やさない。**ローカルヘッダー・中央ディレクトリ・
終端レコードを直接書く（ファイル名固定・単一ファイルなので一般処理が要らない）。

**出所は実装**（`build.mjs`）。[`design/AS_BUILT.md`](../../../../AS_BUILT.md) §0。
**根の親に残すもの10 が「既存の `prismatic-duel/build.mjs` はこの仕様を満たしている（流用可）」
と明記している。**

### 1.3 実測（2026-09-04）

```
inlined  20,579 bytes
zip       8,918 bytes (67.0% of 13,312)
headroom  4,394 bytes
```

| 段 | 意味 | 根の 5-A-1 の基準 |
| --- | --- | --- |
| ソース | 人が書くコード | **予算の単位にしない** |
| **inlined** | minify して1枚へ畳んだバイト数 | **配分の単位**。自主ゲート 28,000 |
| **ZIP** | 提出物 | **全体で1つのゲート。合否を決めるのはこれ**（13,312） |

**現在 67.0%。余裕 4,394 bytes。**

> ⚠️ **これは「交代あり・安全席検査なし」の実装の数字である。**
> 交代を削ると減り、安全席の検査（`gen.audit`）を足すと増える。
> **どちらの量も見積もっていない**（`audit` の 7-2）

### 1.4 読めるソースも提出する（根の 5-A-5）

**遊べる ZIP と、ビルド可能な読めるソースの両方を提出する。**

- ZIP に入るのは**圧縮済みの `index.html` 1枚**
- リポジトリには**コメント付きのソース**が残る
- **開発専用の検査関数は、圧縮時に未使用として落ちる**
  （実装の `validateBoss` がそうなっている）

## 2. なぜ要るのか

**受け入れ条件「提出可能」は、`shell` が無ければ存在しない。**

根はこれを `deferred` にしている（実行主体の `implement` 役割が未作成のため）。
**しかし `shell` の実体は既に動いており、ZIP は 67% で通っている。**

**`deferred` が解除されたとき、最初に必要になるのがこのノードである。**

**そして容量の観測点はここしか無い。**
全ノードが「◯◯ bytes 以内」という受け入れ条件を持つが、
**それを測る手段を持っているのは `shell` のビルドだけ**である。
