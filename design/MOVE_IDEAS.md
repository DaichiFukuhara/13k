## 0. この制約の中で作れるもの・作れないもの

翻訳の前に、**うちの箱の形**を確認する。

### 技の表現は9要素だけ（`gen` の親に残すもの4）

| 添字 | 意味 | 値域 | 実値 |
| --- | --- | --- | --- |
| `S` | 形状 | 0〜5 | SWEEP / THRUST / SLAM / CHARGE / SHOT / RAIN |
| `D` | 威力 | 1〜4 | HP から直接引く |
| `R` | 射程 | 1〜4 | 48 / 82 / 136 / 250 px |
| `W` | 予備動作 | 1〜4 | 24 / 36 / 54 / 80 F |
| `A` | 持続 | 1〜3 | 5 / 8 / 12 F |
| `C` | 攻撃後硬直 | 1〜4 | 18 / 32 / 50 / 76 F |
| `T` | 追尾 | 0〜2 | 予備動作中の標的更新と弾の曲がり |
| `N` | 多段 | 1〜3 | 段間隔は `持続 + 10F` |
| `F` | 宣言 | ビット和 | 移動 / ジャンプ / パリィ |

### ✅ 作れる

- 横軸上の間合いの押し引き、予備動作の読み合い
- 床付近と高さのある攻撃の撃ち分け（**ジャンプの可否がここで決まる**）
- 弾・追尾弾・落下攻撃・突進
- 多段（段間隔が固定なのでリズムになる）
- 第2形態（最終ボスのみ・固有技の強化）
- 防御能力4種（なし / ARMOR / BARRIER / SHIELD）

### ❌ 作れない（設計上の制約）

| 作れないもの | 理由 |
| --- | --- |
| **ボスがジャンプする** | Y は**プレイヤーのジャンプ中だけ**の回避軸（根の 1.7）。ボスは床から離れない |
| **画面外からの攻撃** | 1画面固定・スクロールなし |
| **複数体・召喚** | `duel` の 6「今回は決めない」 |
| **地形・足場** | 根の 1.7「床は平面。落下死なし、足場なし」 |
| **プレイヤーの成長・装備** | 根の 1.8。奪取も**置換であって成長ではない**（1.10） |
| **掴み（パリィ不可の確定ダメージ）** | 根の不変条件10「すべての生成攻撃は反射神経に依存しない回答を最低1つ持つ」に抵触 |

### ⚠️ 作れるが今は生成されない

**3,000シード×3tier = 9,000体の実測**（`node prismatic-duel/moves.mjs stats 3000`）:

| 色 | 出現率 | なぜ少ないか |
| --- | ---: | --- |
| 無色 | **38.5%** | どの特性も閾値に届かない技 |
| 藍（追尾） | 19.8% | SHOT と RAIN だけ |
| 黄（高速） | 14.7% | 1体に1つまでの制限 |
| 青（長射程） | 13.4% | |
| 赤（高威力） | 8.8% | |
| **紫（多段）** | **3.2%** | **固有技にしか付かない** |
| **橙（長持続）** | **1.5%** | **同上** |

**紫と橙がほぼ出ない。**「7色を集める」（根の 1.10）を体験にするなら、ここが効く。

## 1. 予備動作の読み合い

### 1.1 溜めてから撃つ（長い予備動作 × 高威力）

**出典**: Hollow Knight のボス全般、Blasphemous、Salt and Sanctuary。
2Dソウルライクの基本形。

**何が面白いか**: **予備動作が長いほど、プレイヤーは「今なら殴れる」と誘惑される。**
欲張ると発生に間に合わない。**根の 1.1 の4「欲張ると次の予備動作に間に合わない」そのもの。**

| 9要素 | 値 |
| --- | --- |
| `S` | SWEEP / SLAM |
| `D` | 4（最大） |
| `W` | 4（80F） |
| `C` | 3〜4（50〜76F） |
| `T` `N` | 0 / 1 |

**奪うと**: 危険度が低い（`WIND_COST[4]=−2`、`REC_COST[4]=−5`）ので**消費 12〜16 と安い。**
遅いが連発できる。**素手の上位互換に近いので、最初に取る技として置きやすい。**

**生成済み**: ✅ よく出る

---

### 1.2 フェイント（短い予備動作 × 低威力の連打）

**出典**: Furi の近接フェーズ、Nine Sols。

**何が面白いか**: **短い予備動作は反応では間に合わない。**
だから「予備動作を見てから避ける」ではなく「**位置で避ける**」ことになる。
**根の 1.3 の黄の設計（射程＝危険包絡で払う）はまさにこれ。**

| 9要素 | 値 |
| --- | --- |
| `S` | THRUST |
| `D` | 1〜2（`harden` が強制） |
| `W` | 1（24F） |
| `R` | 1〜2（短い） |
| `C` | 1〜2 |

**奪うと**: 危険度が高い（`WIND_COST[1]=+4`）ので**消費 26〜30。**
硬直の隙に差し込めるが、**スタミナが3回で枯れる。**

**生成済み**: ✅ 1体に1つまで

---

### 1.3 二段構え（同じ予備動作から2つの技が出る）

**出典**: Sekiro の見切り、Cuphead のボスの派生パターン。

**何が面白いか**: **予備動作が同じなら、色と範囲でしか区別できない。**
「読む」が本当に読みになる。

**⚠️ うちでは作れない。**技は1つの予備動作から1つの攻撃しか出さない（共通語彙「技」の定義）。
**作るなら根の決定の修正が要る。**

**代替案**: **同じ形状で予備動作長だけが違う2つの技**をセットに入れる。
`gen` の役割枠は形状で分けているので、**枠1と枠2を同じ形状にする**と近いことが起きる。

## 2. 空間の使い方

### 2.1 地面を走る衝撃波（ジャンプで越える）

**出典**: Mega Man のガッツマン系、Hollow Knight の False Knight、Cuphead の地上ボス。

**何が面白いか**: **ジャンプが回答になる唯一の形。**
根の 1.7 が「床付近に当たるものはジャンプで越えられる」と定めた根拠がこれ。

| 9要素 | 値 |
| --- | --- |
| `S` | **SWEEP**（床上24pxの帯） |
| `R` | 3〜4（画面を横断する） |
| `W` | 2〜3 |
| `F` | 移動 / **ジャンプ** / パリィ |

**奪うと**: 射程が長いので消費が高い。**遠くから刺せるが連発できない。**

**生成済み**: ✅ SWEEP は 21.4%

> 🧭 **`audit` の検査 C が「`JUMPABLE` の技が0個なら不合格」としているのは、
> これを1体に必ず1つ入れるためである。**ジャンプが一度も要らないボスを作らない。

---

### 2.2 上から降ってくる（影で予告）

**出典**: Cuphead の弾幕、Hollow Knight の Mantis Lords、Dead Cells の落下攻撃。

**何が面白いか**: **横軸の逃げ場が「点」で消える。**
移動だけで避けられるが、**どこへ逃げるかを先に決める必要がある。**

| 9要素 | 値 |
| --- | --- |
| `S` | **RAIN**（天井から床までの柱） |
| `N` | 2〜3（段ごとに落下 X が違う） |
| `T` | 0〜2（追尾なら予備動作中に狙いが動く） |
| `W` | 3〜4（長め。避ける時間を与える） |

**段ごとの X**: `clamp(標的X ± (55 + 18×段), 30, 幅−30)` — **左右交互に広がる。**
**中央に立つと2段目以降が来る。**端へ寄るのが回答。

**奪うと**: 多段なら1段あたり威力 `7/段数`。**総ダメージは同じで体勢を削りやすい。**

**生成済み**: ✅ RAIN 15.5%。ただし**多段は固有技だけ**

---

### 2.3 突進（自分が動いてくる）

**出典**: Hollow Knight の Hornet、Titan Souls、Furi。

**何が面白いか**: **ボスが動くので「離れれば安全」が成立しない。**
`audit` の A（安全席）が**危険包絡にボスの移動を含める**のはこれのため。

| 9要素 | 値 |
| --- | --- |
| `S` | **CHARGE**（`active` 中にボス本体が前進） |
| 速度 | `3.2 + 射程段 × 0.72` px/F |
| `F` | 移動 / **ジャンプ** / パリィ |

**⚠️ 黄（高速）と組み合わせられない。**根の 1.3 が「黄の技はボスの移動を伴わない」と定める。
**予備動作中に踏み込む技に黄は付かない。**

**奪うと**: **プレイヤーが前進する攻撃になる。**間合いを詰めながら殴れるが、
**硬直中に敵の懐にいる**ので反撃を受けやすい。**性格が最も変わる技。**

**生成済み**: ✅ CHARGE 15.8%

---

### 2.4 追尾弾（位置取りを無効化する）

**出典**: Cuphead のホーミング弾、Mega Man X のホーミングミサイル。

**何が面白いか**: **「そこに立っていれば安全」を壊す。**
だから**根の 1.3 は「黄 × 藍」を禁止している** — 速い上に追ってくると回答が消える。

| 9要素 | 値 |
| --- | --- |
| `S` | **SHOT** |
| `T` | 1〜2 |
| 曲がり | 毎フレーム `vy += sign(プレイヤーY − 弾Y) × T × 0.018`、±1.3 に制限 |

**回答**: **パリィで反射できる**（`duel` の 4.1）。反射弾は所有者が反転してボスへ飛ぶ。

**奪うと**: **追尾は捨てる**（`duel` の変換規則）。プレイヤーは標的を持たないため。
**直進弾になる。**

**生成済み**: ✅ 藍 19.8%（最多の有色）

## 3. 時間の使い方

### 3.1 残留する床（長持続）

**出典**: Blasphemous の血だまり、Hollow Knight の毒、Dead Cells の炎。

**何が面白いか**: **攻撃が終わっても場所が使えない。**
**空間が時間とともに狭くなる。**位置取りの意味が持続する。

| 9要素 | 値 |
| --- | --- |
| `A` | **3**（12F。持続が最大） |
| `S` | SLAM / RAIN |
| 色 | **橙** |

**奪うと**: 危険度に `+2` されるので消費が上がる。**置いて距離を取る使い方になる。**

**生成済み**: ⚠️ **1.5% しか出ない。固有技だけ。**
**12F は「残留」と呼ぶには短い** — 体感を作るなら持続の段をもう1つ増やすか、
`ACTIVE` の値を上げる必要がある（**`gen.move` の変換表を触る**）。

---

### 3.2 リズムのある多段

**出典**: Cuphead の3連射、Nine Sols の連撃、Mega Man のボス。

**何が面白いか**: **段間隔が一定なら、リズムで覚えられる。**
根の 1.9 の2点目（学習で勝率が上がる）に直接効く。

| 9要素 | 値 |
| --- | --- |
| `N` | 2〜3 |
| 段間隔 | **`持続 + 10F`**（固定） |
| `D` | 3段なら **1 に強制**（`harden`） |

**回答**: ロールの無敵 11F は**1段しか抜けられない。**
段間隔が 15〜22F なので、**連続で抜けるにはパリィを繰り返す**か、包絡の外へ出る。

**奪うと**: 1段あたり威力 `7/段数`。**体勢削りが段数ぶん有利。**

**生成済み**: ⚠️ **3.2%。固有技だけ**

---

### 3.3 フェーズ移行（HP 半分で変わる）

**出典**: ほぼ全ての2Dボス。Hollow Knight、Cuphead、Furi。

**何が面白いか**: **覚えたパターンが途中で崩れる。**「もう一度学ぶ」が1戦の中で起きる。

**うちの実装**: 最終ボスのみ。HP 50% で**固有技の威力・予備動作・硬直を +1**。
75F の演出中は敵弾が消える。

> 🔒 **設計では `gen` が両形態を事前に検査する**（`duel` の `d1`）。
> **戦闘中に技を書き換えない。**実装はまだ書き換えている（未対応）。

**拡張案**: 変異を「強化」ではなく「**別の技への差し替え**」にすると、
**第2形態で初めて見る技**が出せる。ただし `audit` が両方を検査する必要がある。

## 4. 奪取（根の 1.10）に効くアイデア

### 4.1 元祖: ボスを倒すと武器が手に入る

**出典**: **Mega Man**（1987）。ボスを倒すとその武器を得て、他のボスの弱点になる。
Kirby のコピー能力も同系。

**うちとの違い**:

| | Mega Man | **うち（1.10）** |
| --- | --- | --- |
| 所持数 | 倒したぶん全部 | **常に1つ** |
| 強くなるか | **なる**（弱点で大ダメージ） | **ならない**（威力は正規化） |
| 何が変わるか | 火力と相性 | **間合いと速さ** |

**「弱点」を作らないのは根の 1.8 のため。**プレイヤー側の成長で難易度を下げない。

### 4.2 奪って性格が最も変わる技

| 技 | 奪うとどうなるか | 消費 |
| --- | --- | ---: |
| **CHARGE**（突進） | **前進しながら殴る。**間合いを詰める攻撃になる | 中 |
| **SHOT**（弾） | **遠距離攻撃になる。**追尾は消えて直進 | 高（射程が加点） |
| **RAIN**（落下） | **離れた場所を叩ける。**自分の真上ではない | 中〜高 |
| **SWEEP**（横薙ぎ） | **横に広い。**近接の間合いが伸びる | 中 |
| **SLAM**（叩きつけ） | **自分を中心に広い。**囲まれない1画面では素直な強化 | 中 |
| **THRUST**（突き） | 素手と同系。射程と速さだけ変わる | 低〜中 |

**SHOT と CHARGE が最も面白い**（戦い方が変わる）。
**THRUST は差が出にくい**（素手と同形状）。

### 4.3 奪う対象を絞る案

| 案 | 効果 | 欠点 |
| --- | --- | --- |
| **全技から選ぶ**（現在の設計） | 選択の重みが最大 | 6択は迷う。無色が多いと地味 |
| **固有技だけ** | **紫・橙が手に入りやすい**（固有技に集中しているため） | 選択がなくなる（1択） |
| **有色だけ** | テーマが立つ | 無色 38.5% を捨てるので候補が減る |
| **形状が違うものだけ** | 持ち替えの意味が保証される | 実装が増える |

## 5. 現状の生成では出ないが、入れると効きそうなもの

**どれも `gen` を触る。人間の判断が要る。**

| # | アイデア | 何が要るか | 効くところ |
| --- | --- | --- | --- |
| 1 | **紫・橙を通常枠にも出す** | 多段・長持続の固有技限定を外す。危険度の帯域を調整 | 「7色を集める」（1.10・テーマ） |
| 2 | **持続の段を増やす**（12F → 20F 以上） | `ACTIVE` の変換表を触る | 「残留する床」が体感になる |
| 3 | **無色の技に色を割り当てる** | 閾値を下げる（威力2で赤、射程3で青…） | 無色 38.5% が消える |
| 4 | **枠ごとに色を割り当てる** | 役割枠に色の制約を足す | 1体で必ず複数色が揃う |
| 5 | **第2形態で技を差し替える** | `gen` が差し替え後も検査する | 「もう一度学ぶ」が強くなる |
| 6 | **形状ごとに固有の予備動作の見た目** | `read.tell.telegraph` の担当 | 初見の読みやすさ |

## 7. 使い方

1. **アイデアを選ぶ**（§1〜4 から）
2. **9要素へ翻訳する**（各項の表がその形になっている）
3. **`gen` を触る**なら `prismatic-duel/game.js` の上から350行:
   `threat()` / `limits()` / `budgetCap()` / `harden()` / `balance()` / `makeMove()` / `generateBoss()`
4. **確かめる**:
   - `node prismatic-duel/test.mjs` — 30,000体の決定論と公平性
   - `node prismatic-duel/moves.mjs 7` — seed 7 の技構成を人間が読める表で
   - `node prismatic-duel/moves.mjs stats 3000` — 9,000体の分布
   - `node prismatic-duel/sim.mjs 40` — 勝率と撃破時間
5. **設計を変えるなら**、まず `design/tree/` の該当ノードを直す（子は親を選び直さない）
